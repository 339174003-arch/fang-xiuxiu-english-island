# 方羞羞英语岛｜微信小程序源码

这是现有小学英语岛的原生微信小程序版本，保留六个年级的 108 项题库，提供每日混合挑战、年级闯关和开口跟读。

## 导入与预览

1. 下载并解压本目录。
2. 安装微信开发者工具，选择“导入项目”，项目目录选择本文件夹。
3. 项目当前使用 `touristappid` 方便本地开发预览。准备提交体验版或发布时，在 `project.config.json` 中换成你自己的小程序 AppID，并在微信公众平台将小程序管理员和开发者添加到项目。
4. 在微信开发者工具中编译、预览；真机首次点击“开始跟读”时，微信会请求麦克风权限。

## 功能

- 一到六年级闯关，按六年级到一年级从难到易排列。
- 每次从相应年级或全小学题库随机抽 8 句。
- 点击“听标准读音”播放英语示范音；音频播放完成后才能开始跟读。
- 点击“开始跟读”后才请求麦克风。程序在本机计算音量变化，不保存、不上传录音。
- 必须听完示范音并检测到开口声音，才能进入下一句。
- 星星进度保存在本机。

## 音频和权限配置

项目用微信 `InnerAudioContext` 播放英语示范音，先尝试 Google 翻译英语朗读，再尝试有道词典发音。正式真机运行时，需要在微信公众平台“开发管理 → 开发设置 → 服务器域名”中按平台要求配置对应的 HTTPS 音频域名（通常为下载域名）；未配置时，开发者工具关闭域名校验可用于本地调试，正式版仍需配置并真机验证。

首次跟读会申请 `scope.record` 麦克风权限。录音用于本机声音强度检测，不调用语音转文字服务。不同手机的录音帧格式与音量阈值可能有差异，发布前请在 iOS 和 Android 真机各试一次。

## 目录

```text
app.js / app.json / app.wxss      小程序全局配置
pages/index/                      首页和年级地图
pages/practice/                   跟读、播放和本机麦克风检测
data/curriculum.json              六年级完整题库
project.config.json               微信开发者工具项目配置
```

小程序 AppID、公众平台域名配置、微信审核和发布必须由小程序管理员在自己的微信公众平台账号中完成；本源码包不包含账号密钥。
